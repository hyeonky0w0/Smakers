## 🛠 Tech Stack
- **Framework**: Spring Boot 3.x
- **Language**: Java 17
- **Database**: H2 (Development), MySQL (Production)
- **Build Tool**: Gradle
- **API Documentation**: Swagger (Springdoc OpenAPI)

## 🏗 Project Structure
- `src/main/java`: 백엔드 소스 코드
- `src/main/resources`: 설정 파일 (application.yml 등)
- `.github`: 이슈 및 PR 템플릿
